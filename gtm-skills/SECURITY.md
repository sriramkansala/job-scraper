# Security

Skills in this library are instructions that AI agents execute against live CRMs, inboxes, and company data. We review every submission for exfiltration, hidden endpoints, prompt injection, credential harvesting, and ungated destructive actions before merge (see [CONTRIBUTING.md](CONTRIBUTING.md)).

## Reporting

Found a skill that does something it shouldn't — or a way to sneak one past review?

- Preferred: [open a private security advisory](https://github.com/swan-gtm/gtm-skills/security/advisories/new)
- Or email **security@getswan.com**

Please don't open a public issue for security reports. We aim to respond within 2 business days; confirmed-malicious skills are pulled from the library and the product immediately.
